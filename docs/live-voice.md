# 라이브 통화

입력창의 마이크 버튼은 이 대화의 에이전트와 음성으로 통화합니다. 통화 모델은 Codex live이고, 혼자 답할 수 없는 일은 지금 세션에 위임한 뒤 그 답을 읽어 줍니다. 통화 전사는 세션 기록에 남습니다. 통화 중에는 같은 버튼이 종료 버튼이 됩니다. 좁은 화면에서는 모델 선택 등 다른 조작부와 함께 줄을 나누고, 화면 높이가 부족하면 할 일·배너 영역을 스크롤하면서 입력창과 종료 버튼을 사용할 수 있습니다. 확정된 사용자 발화 전체가 끝내는 말(「통화 끊어」, 「알았어, 끊어봐」, 「아니 통화 종료하라고」, 「통화 종료해 줘」 등)이어도 통화가 끝납니다. 「끊지 마」, 「끊어도 돼?」, 「끊어라고 했어」처럼 부정·질문·인용이나 「통화 종료가 안 먹네」 같은 문제 설명은 끝내지 않습니다.

에이전트와의 통화는 Codex 목소리를 사용하며 별도의 음성 합성 서비스나 API 키는 필요하지 않습니다. 별도 「통역」 화면도 같은 Codex 연결을 씁니다.

## Codex 목소리

설정 창 왼쪽 **구성**(Configuration) 메뉴의 **통화 음성**에서 에이전트 통화와 Codex 통역이 쓰는 목소리를 고릅니다. 고르면 바로 저장되고 다음 통화부터 적용됩니다. 처음 값은 Sol이고, 한국어 목소리 Haetsal(햇살)·Hanul(하늘)을 비롯한 25개 중에서 고를 수 있습니다. 이 값은 omp 설정의 `live.voice`이며 설정 창 「제공자」 탭의 「Live 음성」과 같은 값입니다.

같은 화면의 **말 빠르기**에서 「보통」과 「천천히」를 고를 수 있습니다. 「천천히」를 고르면 다음 통화부터 통화와 통역 모두 또박또박 느리게 말합니다. 속도 숫자를 통화에 직접 넣는 방식은 Codex 통화가 연결되지 않아 쓰지 않고, 통화 지시에 느리게 말하라는 규칙을 붙입니다. 그래서 정확한 배속이 아니라 대략 느려지는 정도이며, 「빠르게」는 지시로는 빨라지지 않아 두지 않았습니다.

| 무엇 | 어디 | 비고 |
|------|------|------|
| Codex 목소리 | omp 설정 `live.voice` | 처음 값 `sol`. 통화마다 설정을 다시 읽으므로 열려 있는 세션에서도 다음 통화부터 바뀝니다 |
| 말 빠르기 | `<agentDir>/cuelo-live-settings.json`의 `pace` | `normal`(처음 값) 또는 `slow`. 통화마다 다시 읽습니다 |

## 통화 중 동작

- **누가 말하는가.** 통화를 시작할 때 서버가 이 세션의 Main을 정합니다. 규칙은 화면 얼굴과 같습니다. 캐릭터가 하나로 예약된 provider는 계정 수와 관계없이 그 캐릭터입니다(Codex→YUKI 등). Anthropic은 **이 세션에 pin된** OAuth 계정의 저장 순서로 정합니다(0→RIN, 1→MIO). 같은 모델을 쓰는 두 세션이 동시에 열려 있어도 각자의 pin으로 갈립니다. pin이 아직 없으면 추측하지 않습니다. 이 결과는 통화 기록의 얼굴·이름 표시에만 쓰이고, 목소리는 늘 Codex 목소리입니다. 통화 답변은 그 캐릭터의 얼굴과 이름으로 보이며 「기본 음성」이라는 표시가 함께 붙습니다. 통화 도중 Main이 바뀌어도 그 통화의 표시는 시작할 때 정한 캐릭터를 따릅니다.
- **Main 대화 공유.** 통화가 열리면(`session.started`) 서버가 이 세션의 최근 사용자·Main 답변과 지난 통화 턴을 오래된 순서로, 한 항목 400자·전체 약 2,400자까지 잘라 `session.context.append`의 `commentary` 채널로 넘깁니다. 대화를 이어 가기 위한 배경이며 읽으라는 내용이 아닙니다. 통화 중 채팅창으로 보낸 요청처럼 위임이 아닌 Main 턴이 끝나면, 그 요청은 `commentary`로, Main의 마지막 답은 위임 결과와 같은 「Agent Final Message」 형식으로 넘겨 통화가 자기 답처럼 읽게 합니다. 위임한 턴의 답은 전처럼 위임 채널로만 갑니다.
- **통화 기록.** 확정된 사용자·assistant 턴만 세션 기록에 남깁니다. 예전에 캐릭터 통화 음성으로 한 통화의 기록은 그때 저장된 화자 표시를 그대로 읽습니다.

## 통역

통역 화면은 **Codex Live**를 씁니다. 별도 API 키 없이 기존 ChatGPT 로그인으로 쓰며, 마이크 입력과 통역 음성은 Codex(OpenAI)로 전송됩니다. 예전에 있던 Google Cloud(Gemini 라이브) 통역 연결은 없앴습니다. 대화 분위기와 나·상대의 성별·나이대 설정은 통역 지시에 들어가지만, 모든 문장에서 원하는 말투가 그대로 나온다고 보장하지는 않습니다.

통역 설정의 **「통역 음성 듣기」**는 기본으로 꺼져 있습니다. 꺼져 있을 때는 소리 없이 자막으로만 통역이 표시되며, 스피커에서 소리가 나지 않아 마이크가 차단되지 않으므로 통역이 표시되는 동안 하는 말도 함께 통역됩니다. 통역 중에 설정을 바꾸면 바로 적용됩니다.

음성을 켜면 **「통역 음성이 나올 때 마이크 끄기」**가 나타나며 기본으로 켜져 있습니다. 통역 음성이 재생되는 동안과 끝난 뒤 약 0.5초 동안 마이크를 차단하여, 휴대전화 스피커 소리가 다시 마이크로 들어가 재통역되는 일을 막습니다. 이 시간 동안 상대방이 하는 말은 통역되지 않습니다. 이어폰을 쓸 때는 이 설정을 끄면 되며, 통역 중에 바꿔도 바로 적용됩니다.

**「AI 소음 제거」**는 기본으로 꺼져 있습니다. 켜면 마이크 소리가 통역을 위해 전송되기 전에 브라우저 안에서 소음 제거를 거치므로 시장이나 거리처럼 시끄러운 곳에서 유용하며, 이를 위해 오디오가 별도의 곳으로 전송되지는 않습니다. 목소리가 먹먹하게 들리면 이 설정을 끄세요. 통역 중에 전환해도 다시 연결할 필요 없이 바로 적용되며, 소음 제거를 시작할 수 없거나 도중에 멈추더라도 원래 마이크 소리로 통역이 계속됩니다.

**「빠른 초안 자막」**은 기본으로 꺼져 있으며, 한 번 켜 두면 설정이 유지됩니다. 켜면 OpenAI의 전용 번역 모델(`gpt-realtime-translate`)이 단일 마이크 하나로 양방향 음성을 받아 흐린 글씨의 초안 자막을 먼저 보여주므로, 두 사람이 휴대폰 하나를 사이에 두고 마주 보며 대화할 때 아무 버튼을 누르지 않아도 작동합니다. 이후 Codex Live의 번역이 도착하면 같은 자리에서 초안을 대체합니다. 초안 자막은 화면 표시 전용이어서 음성 출력과 재연결에 쓰이는 대화 기록은 모두 Codex Live에서만 가져오며, 전용 번역 모델이 들은 말을 목표 언어로 그대로 따라 하기만 한 초안은 버려지고 Codex가 끝내 대체하지 않은 초안은 약 20초 뒤에 사라집니다. 이 설정이 켜져 있는 동안에는 마이크 음성이 전용 번역 모델로도 전송되며, 별도의 API 키 없이 동일한 ChatGPT 로그인을 사용합니다. 켜 둔 동안 추가 요금이 발생할 수 있으나 실제 과금 여부는 확인되지 않았습니다.

소음 제거 준비가 지연되면 3초 후 원래 마이크로 전환하고, 빠른 초안 자막 준비가 실패하면 초안 연결과 오디오 자원만 정리한 뒤 본 통역은 그대로 이어갑니다.

화면은 들은 원문과 통역을 서로 다른 자막 흐름으로 보여 줍니다. 공급자가 원문과 번역을 같은 시점이나 같은 단위로 보내지 않을 수 있어 두 자막을 일대일로 맞추지 않습니다. 다시 연결할 때는 최근 전사를 문맥으로 넘기고, 언어를 가리기 어려운 이름이나 숫자만으로는 화자를 정하지 않습니다.

## 확인되지 않은 것

- 위임 밖에서 넘긴 맥락(`session.context.append`)은 SDK에 계약만 있고 SDK 자신은 쓰지 않습니다. 통화 모델이 `commentary` 이력을 소리 내 읽지 않는지, 사용자 발화 없이 넘긴 채팅 답을 바로 말하는지는 실제 통화로 확인하지 않았습니다.
