# 스킬 설치와 업데이트

CUELO는 설정 > Skills의 **Skill 추가** 또는 설치된 스킬의 **업데이트** 버튼으로 `skills.sh`의 외부 에이전트 스킬을 설치하거나 업데이트할 때, 실제 스킬 폴더를 변경하기 전에 정적 보안 검사를 먼저 실행합니다.

## 설치 및 업데이트 전 보안 검사

스킬 폴더나 잠금 파일에 아무것도 쓰기 전에, CUELO는 격리된 HOME 환경의 임시 작업 영역에 패키지(또는 업데이트할 새 내용)를 먼저 내려받습니다. 그다음 발견된 모든 스킬 폴더를 SkillSpector로 검사합니다. 검사기는 PATH 또는 `~/.local/bin`에서 찾은 `skillspector` 실행 파일이며, CUELO는 그 버전을 확인하지 않습니다. 권장 버전은 아래 [SkillSpector 설치](#skillspector-설치)에 있습니다.

- **정적 분석 전용:** `--no-llm` 옵션으로 실행되므로 스킬 내용이 LLM으로 전송되지 않습니다.
- **환경 격리:** 검사 프로세스는 환경 변수에서 자격 증명을 제거한 상태로 실행됩니다.
- **시간 제한:** 한 번의 요청에서 패키지 내 모든 스킬을 합쳐 약 3분의 전체 검사 시간이 주어지며, 화면에는 `보안 검사 중 (최대 2~3분)`이 표시됩니다. 규모가 큰 스킬은 약 2분이 걸릴 수 있습니다.

패키지에 여러 스킬이 포함된 경우 가장 나쁜 검사 결과를 기준으로 판정합니다. SkillSpector가 종료 코드 0과 함께 `SAFE`를 반환하고 분석이 완료(`complete` 또는 `complete_with_caveats`)된 경우에만 통과하며, 이때는 즉시 설치 또는 업데이트가 적용됩니다.

알 수 없는 참조, 네트워크 오류, `skills` CLI 오류 등으로 패키지를 가져올 수 없는 경우에는 확인 절차로 넘어가지 않고 일반 오류로 처리합니다.

## 검사 결과에 따른 확인 절차

통과하지 못한 경우 아직 아무것도 설치되거나 변경되지 않으며, CUELO는 화면에 결과를 표시하고 **그래도 설치**(또는 **그래도 업데이트**)와 **취소** 버튼을 제공합니다.

| 결과 구분 | 표시 내용 및 원인 |
| --- | --- |
| 위험 감지 | 권고 등급(`CAUTION` 또는 `DO_NOT_INSTALL`), 위험 점수(0~100), 규칙 ID와 파일 위치가 포함된 최대 5개의 탐지 항목을 표시합니다. 공식 스킬도 탐지되는 경우가 많아 차단 대신 사용자 확인을 요청합니다. |
| 검사기 없음 | 이 PC에 SkillSpector가 설치되어 있지 않아 스킬을 검사할 수 없는 상태입니다. |
| 검사 미완료 | 시간 초과, 실행 실패, 읽을 수 없는 보고서 생성, 또는 스킬 일부만 분석된 경우입니다(`SAFE`라도 부분 분석이면 미완료로 처리합니다). |

## 확인 후 적용 및 무결성 검증

**그래도 설치** 또는 **그래도 업데이트**를 누르면 검사 당시의 콘텐츠 해시가 서버로 전송됩니다. 서버는 다시 검사를 실행하지 않고 패키지를 새로 내려받아 모든 스킬 폴더의 해시를 직접 다시 계산한 뒤, 이전 해시와 일치할 때만 설치를 진행합니다. 그사이에 원격 내용이 바뀌었다면 오류를 내고 중단하므로 검사를 다시 실행해야 합니다.

설치가 끝난 뒤에도 CUELO는 실제 설치된 폴더를 검사했던 내용과 비교합니다. 일치하지 않으면 해당 스킬 폴더와 잠금 파일을 이전 상태로 복구하고 오류를 보고합니다.

## 프로젝트 범위와 제한 사항

프로젝트 범위에서 스킬을 설치하거나 업데이트하려면 해당 프로젝트가 신뢰 상태여야 합니다([`project-trust.md`](./project-trust.md) 참고). 신뢰하지 않은 프로젝트의 요청은 403 오류로 거부됩니다.

- 에이전트가 학습으로 만드는 관리형 스킬(`~/.omp/agent/managed-skills`)은 이 설치·업데이트 경로로 들어오지 않으므로 검사 대상이 아닙니다. 설치 경로는 `skills` CLI가 쓰는 Claude 레이아웃(`~/.claude/skills`, 프로젝트의 `.claude/skills`)이고, 업데이트 버튼은 `skills`·`.claude/skills` 폴더에 잠금 파일 항목이 있는 스킬에만 나타납니다.
- 검사용 임시 공간에는 git 설정과 자격 증명을 넘기지 않으므로, 비공개 GitHub 저장소의 스킬은 설치하거나 업데이트할 수 없으며 공개 저장소의 스킬만 지원합니다.
- LLM 분석 모드는 지원하지 않으며, 이전 승인을 기억하지 않으므로 같은 스킬도 다음에 다시 검사합니다.
- 이 검사는 정적 확인일 뿐 스킬의 안전을 보장하지 않으므로, 탐지 항목이 있는 스킬은 확인 버튼을 누르기 전에 직접 검토하세요.

## SkillSpector 설치

SkillSpector는 선택 구성 요소이며, 설치하지 않아도 CUELO는 동작하지만 스킬을 설치하거나 업데이트할 때마다 검사하지 못했다는 경고와 확인 단계가 나옵니다. 설치하려면 아래 명령을 실행합니다. 설치 위치는 PATH 또는 `~/.local/bin`이면 됩니다.

`uv tool install --force 'git+https://github.com/NVIDIA/skillspector.git@v2.13.4'`

`uv`가 내려받을 수 있는 Python 3.12 이상이 필요합니다.

근거 코드: `lib/skill-scan.ts`, `app/api/skills/install/route.ts`, `app/api/skills/update/route.ts`.
