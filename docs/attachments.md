# 파일 첨부와 음성 받아쓰기

입력창에 파일을 끌어 놓거나, 붙여넣거나, 파일 선택 버튼으로 첨부합니다. 작은 텍스트 문서는 본문으로 전달하고, 저장형 첨부는 원본을 서버에 보관한 뒤 파일 경로를 대화에 넣습니다. 라이브 음성 통화와 녹음 파일 받아쓰기는 별개 기능입니다.

## 파일 크기

**설정 → 첨부 파일**에서 저장형 첨부의 파일당 업로드 한도를 바꿉니다. 기본값은 **100MB**입니다. 서버는 업로드를 청크 단위로 저장하며, 제한을 넘거나 전송을 중단하면 완성되지 않은 업로드를 정리합니다.

이 한도는 파일 원본의 저장 한도입니다. 모델에 직접 넣는 이미지·문서 본문의 한도와는 다릅니다. 큰 파일을 저장했다고 전체 내용이 모델 컨텍스트에 한꺼번에 들어가는 것은 아닙니다.

## 음성 파일

음성 받아쓰기는 모델 역할 `draft`가 가리키는 모델(Google 인라인 오디오 API)이 기본으로 맡고, 그 모델 제공자의 자격이 필요합니다. 사용량과 과금은 해당 계정의 조건을 따릅니다. 역할이 비어 있거나 모델을 찾지 못하면 Google Cloud Vertex 자격(`gcloud auth application-default login`과 `GOOGLE_CLOUD_PROJECT`)으로 기본 모델을 씁니다. 인라인 오디오를 지원하지 않는 채팅 API는 음성을 전송하기 전에 거부합니다.

- 작은 음성 파일은 첨부 후 받아쓰기를 시작합니다.
- 큰 음성 파일은 먼저 길이와 예상 전사 요청 수, 과금 안내를 보여 줍니다. **전사 시작**을 눌러야 외부 전사 요청을 보냅니다. 전사를 하지 않고 원본만 첨부할 수도 있습니다.
- 큰 음성은 원본을 보존하고 전사용 사본을 압축·분할합니다. 조각을 순서대로 전사한 뒤 결과를 연결합니다. 표시한 요청 수는 기본 제공자 기준의 계획이며, 오류 재시도나 대체 전사 전환에 따라 실제 요청 수와 사용량이 늘 수 있습니다.
- 기본 전사 호출이 실패하면 이미 완료된 앞부분은 유지하고 실패한 조각과 남은 음성은 기존 ChatGPT/Codex 로그인으로 전사합니다. 언어는 자동 감지합니다. 안전·동의 거부를 다른 제공자로 우회하지 않으며, 전환 후에는 남은 구간에 기본 제공자를 다시 호출하지 않습니다.
- 대체 전사는 음성을 보수적인 15초 단위 MP3 조각으로 나누어 순서대로 전송합니다. 15초는 짧은 테스트를 바탕으로 정한 로컬 분할 기준이며 제공자의 공식 최대 한도가 아닙니다.
- Codex 대체 전사는 비공개·비문서화 엔드포인트를 사용합니다. 계정의 사용량 한도는 확인되지 않았습니다. 시험 응답에는 `asset_ttl='30d'`가 있었지만 실제 보관·삭제 정책은 확인되지 않았습니다.
- 진행 중 취소하거나 일부 조각이 실패하면 전체 전사가 완료된 것으로 표시하지 않습니다. 임시 변환 파일은 정리하고 원본은 보존하므로 오류를 확인한 뒤 다시 시도할 수 있습니다.

파일의 길이·형식과 제공자 응답에 따라 처리 시간이 달라집니다. 예상 요청 수는 금액이나 완료 시각을 보장하지 않습니다.

큰 음성의 분할·변환과 Codex 대체 전사에는 원본 파일 크기와 관계없이 FFmpeg가 필요합니다. 의존성 설치 때 운영체제에 맞는 실행 파일을 내려받으므로 설치 중 네트워크와 디스크 공간이 필요합니다. 다운로드가 막히거나 실행 파일을 사용할 수 없으면 변환 오류를 안내합니다. FFmpeg와 배포 패키지의 라이선스는 [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static) 및 그 배포물을 확인하세요. 작은 음성을 기본 제공자로 직접 전사할 때는 변환하지 않습니다.

## 자동 정리

자동 정리는 기본으로 켜져 있으며 **설정 → 첨부 파일**에서 끌 수 있습니다. 서버 시작 약 1분 뒤 첫 검사를 하고, 실행 중 24시간마다 정리 대상을 확인합니다. 서버가 꺼져 있는 동안에는 삭제하지 않습니다.

삭제 기준은 업로드 날짜가 아닙니다. **어느 대화·분기·초안에서도 사용하지 않는 것으로 확인된 시점부터 7일**이 지난 파일만 다음 검사에서 삭제합니다.

- 대화 기록이나 초안이 참조하는 파일은 기간과 관계없이 보존합니다.
- 전송을 마쳤지만 대화 기록에 저장됐는지 아직 확인되지 않은 첨부도 보존합니다.
- 다른 대화로 fork한 파일은 원래 대화 하나를 삭제했다고 함께 삭제하지 않습니다.
- 업로드나 전사가 진행 중인 원본도 보호합니다.
- 다시 참조하면 미사용 유예 시간을 취소합니다.
- 참조 검사나 파일 정보 확인에 실패하면 삭제하지 않습니다.
- 이 기능 도입 전의 파일처럼 참조·관리 정보가 불확실한 원본은 자동 삭제 대상에서 제외합니다.

탭을 닫거나 한동안 접속하지 않았다는 이유만으로 초안을 버리지 않습니다. 사용 여부가 불확실한 파일이 남을 수 있지만, 자동 정리를 위해 과거 대화의 원본을 추측해서 삭제하지는 않습니다.
