# cuelo-plugins

Promoted Plugin Lab plugins, one folder per plugin id (`<id>/plugin.json` plus its files). The profile sync installs
this folder as `~/.omp/agent/cuelo-plugins/`, where a promoted id hides the trial copy in `~/.omp/agent/plugin-lab/`.
Plugins arrive here only through the nightly loop's reviewed changes. The format is in `skills/plugin-lab/SKILL.md`.
